# Polymer wire coating project -- group 6

This is a repo with...

- the provided notebooks (in... /provided notebooks)
- our port of the notebooks to a python class (wirecoating.py)
- analysis of TRIOS data & plotting (in /trios data)
- optimization of wire coating (in /optimization)

I originally wanted to learn the boundary of melt fracture with a support vector machine, but it turns out the design space for this project is just too simple for that approach to make any sense.
