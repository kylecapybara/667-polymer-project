# Polymer wire coating

Code and data for modeling and optimizing two-layer polymer wire coating.

- `provided notebooks/` — original course notebooks
- `wirecoating.py` — Python class adapted from the provided notebooks
- `trios data/` — rheology data analysis and plots
- `optimization/` — line-speed optimization and sensitivity analysis

We initially considered using a support vector machine to identify the melt-fracture boundary, but the design space was too simple to justify it.
